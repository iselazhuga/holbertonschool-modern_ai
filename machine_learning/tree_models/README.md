# Tree-Based Models

Holberton School Albania, Machine Learning Specialization.

This project covers tree-based models for classification:

- Decision trees, Gini impurity and how splits are made
- Pre-pruning and post-pruning with cost complexity pruning (ccp_alpha)
- Random forests and feature importance
- Boosting: AdaBoost, Gradient Boosting, XGBoost and LightGBM
- Bagging vs boosting, and evaluating classifiers

## Files

| File | Description |
| --- | --- |
| `0-build.py` | Task 0: decision tree classifier |
| `1-train.py` | Task 1: train a tree-based classifier |
| `2-draw.py` | Task 2: print the decision rules of a trained tree |
| `3-generate_predictions.py` | Task 3: predict class labels with a trained tree |
| `4-evaluate.py` | Task 4: classification report (precision, recall, F1) |
