# Linear Models

Holberton School Albania, Machine Learning Specialization.

This project covers linear models for regression and classification:

- Linear regression and its coefficients
- Regression metrics: MAE, MSE, RMSE and R squared
- Regularisation with Ridge and Lasso
- Explaining predictions with SHAP values
- Logistic regression and decision boundaries
- Support vector machines and kernels (linear, poly, RBF)
